# Double Board Bomb Pot · 双人双牌面扑克

一个支持两名玩家通过互联网实时联机的网页版 **Double Board Bomb Pot**。默认是德州扑克（每人 2 张底牌），创建房间时也可以选择奥马哈（每人 4 张底牌）。**全部为虚拟娱乐筹码，不支持充值、提现、真钱下注或现金结算。**

## 游戏已实现的功能

- 私人房间（6 位房间号、邀请链接）、双人实时联机（WebSocket）、断线自动重连
- 服务端密码学随机洗牌；只向各位玩家发送自己的隐藏底牌
- 两组独立的 5 张公共牌，上下各赢取 50% 底池；双方平局时该半池再分割
- 强制底注：每人 20（虚拟筹码）；直接亮出两组翻牌，不进行翻牌前下注
- 翻牌、转牌、河牌依次进行；支持让牌、下注、跟注、加注、弃牌、有效全下
- 服务端牌型判定；德州 7 选 5；奥马哈必须使用 **恰好 2 张底牌 + 3 张公共牌**
- 每人初始 1,000 筹码；每局交替庄位和首位行动者；双方确认后再开下一局
- 自动限制最大下注额为有效筹码额，避免双人桌出现无人可以匹配的超额下注
- PC / 手机浏览器自适应；纯前端静态资源，不依赖 Google Fonts 或外部 CDN
- 零第三方 npm 运行依赖，Node.js 20+ 即可启动

## 玩法（具体房间规则）

这是一种适合 **恰好两个人** 的休闲版规则，不完全等同于某个赌场的正式规程：
1. 双方先投入 20 底注。
2. 同时给上下牌面发 3 张公共牌，进入翻牌圈下注。
3. 正常发上下转牌、河牌并继续下注。全下且无人可再下注时自动发出剩余公共牌。
4. 摊牌时，上、下牌面分别比较各自的最佳五张牌型，各占底池 50%。
5. 若某一牌面平局，则该半池均分（极端情况下多余 1 筹码归座位 1）。
6. 一人筹码归零后，双方准备下一局会重置到各 1,000 虚拟筹码。

## A. 在自己电脑上运行（本机试玩）

首先安装 [Node.js 20+](https://nodejs.org/)，然后：

```bash
cd double-board-bombpot
npm start
```

浏览器打开：**http://localhost:3000**

本地测试可以开两个浏览器或隐身窗口；也可以从第二台同一局域网的设备使用电脑的局域网 IP 访问。**localhost 不能直接让中国的朋友远程访问**，跨国联机必须进行公网部署。

## B. 最省事的公网部署：Render（免费选项）

适合先验证游戏是否能玩，但**不保证中国大陆的网络能访问**：
1. 在 GitHub 创建新的代码仓库，上传本文件夹（不包含 `node_modules`）。
2. 打开 https://dashboard.render.com/，选 **New → Web Service**，连接 GitHub 仓库。
3. 选择 Node，Build Command 用 `npm ci`，Start Command 用 `npm start`，环境 `PORT` 不用手动填写。
4. 部署结束后，Render 会分配形如 `https://项目名.onrender.com` 的公共 HTTPS 地址。
5. 你打开该地址点“创建房间”，把房间链接发给朋友，他用国内网络实测访问和加入。

注意：免费服务闲置时会休眠，房间仅在服务器内存中，**服务实例重启会导致房间和筹码状态丢失**。请勿用于正式比赛或真钱交易。

## C. 推荐给澳洲 + 中国大陆双人使用：香港服务器 + 域名

如果 Render 在国内无法稳定打开，可租一台**香港地区的 VPS**，配置域名和 HTTPS。香港境外托管通常不要求中国大陆网站的 ICP 备案；**这不构成中国大陆一定可访问的保证**，跨境线路仍需实测。

要求：香港 Linux VPS（安装 Docker 和 Docker Compose），一个域名（DNS A 记录指向 VPS IPv4），服务器安全组允许 80、443 TCP。

编辑 `Caddyfile`，将 `play.example.com` 换成你的域名：

```caddyfile
play.yourdomain.com {
    encode zstd gzip
    reverse_proxy game:3000
}
```

在服务器上的本项目目录执行：

```bash
docker compose up -d --build
```

Caddy 负责 HTTPS 证书和 `wss://` WebSocket 反向代理。两位玩家访问同一个 `https://play.yourdomain.com`，房主创建房间并复制邀请链接。

部署后要 **双方分别在澳洲和中国大陆用真实网络** 测试能否打开 HTTPS 页面、能否连接 WebSocket、是否能正常操作和摊牌。

## 当前限制

- 只支持两人；无旁观者、聊天、锦标赛或真钱功能。
- 房间状态仅存服务器内存，重启丢失；断网时座位保留，可用原浏览器自动重连。
- 本机返回首页并不立即释放服务器上的座位；可新建其他房间。
- 本项目尚未进行互联网公开环境的压力测试、安全审计或浏览器全兼容性验证。
